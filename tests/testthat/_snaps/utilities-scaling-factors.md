# .warn_unsupported_scaling_factors only warns for NA factors

    Code
      .warn_unsupported_scaling_factors(row, "MicProtGO", "human", "brain")
    Condition
      Warning:
      The scaling factor MicProtGO (the microsomal protein per gram tissue) is not supported for species "human" and tissue "brain": it is `NA` in the scaling factor table.
      i The result is `NA`.
